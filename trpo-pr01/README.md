# TRPO Course

Информационный портал для курса по веб-разработке.

## Запуск проекта

Этот проект — статическая HTML-страница, поэтому запуск не требует сборки или установки зависимостей.

### Вариант 1: открыть страницу напрямую

1. Откройте файл `index.html` в браузере.
2. Если нужно, можно просто дважды щёлкнуть по файлу или открыть его через браузер вручную.

### Вариант 2: запустить локальный сервер

1. Откройте терминал в папке проекта:
   ```bash
   cd trpo-pr01
   ```
2. Запустите сервер:
   ```bash
   python -m http.server 8000
   ```
3. Откройте в браузере адрес:
   ```text
   http://localhost:8000
   ```

### Вариант 3: через VS Code

1. Откройте папку проекта в VS Code.
2. Установите расширение Live Server (если ещё не установлено).
3. Нажмите правой кнопкой мыши на `index.html` и выберите `Open with Live Server`.

## Структура проекта

- `index.html` — основная HTML-страница
- `styles.css` — стили оформления
- `app.js` — загрузка и отображение данных
- `dataset/navigation.json` — ссылки навигации
- `dataset/content.csv` — данные направлений и расписания

Навигация загружается из `dataset/navigation.json`, а карточки направлений и строки расписания — из `dataset/content.csv`. Для загрузки этих файлов запускайте проект через локальный HTTP-сервер, а не открывайте `index.html` напрямую.

## Примечание

Для корректного отображения страницы лучше использовать локальный сервер, так как некоторые браузеры могут ограничивать доступ к ресурсам при открытии файла напрямую.
