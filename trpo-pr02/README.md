# TRPO ПР №2 — каталог учебных товаров

Проект представляет собой адаптивный каталог товаров на HTML и CSS/SCSS. Сайт работает без JavaScript: карточки каталога подготовлены по данным `dataset/catalog.csv`, а значения темы из `dataset/theme.json` перенесены в SCSS-переменные. Фильтрация категорий реализована средствами CSS.

## Что в проекте

- `index.html` — базовая структура страницы.
- `Index2.html` — адрес старой страницы, перенаправляющий на `index.html`.
- `scss/` — исходные SCSS-модули.
- `css/styles.css` — скомпилированный CSS.
- `dataset/` — исходные данные и настройки темы.

## Как запустить

Откройте `index.html` в браузере. Сервер и установка зависимостей для просмотра не нужны. Для разработки можно запустить локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`. Фильтр категорий использует CSS `:has()` и доступен в актуальных версиях основных браузеров.

## Пересборка SCSS

Для одной компиляции:

```bash
npx sass scss/styles.scss css/styles.css
```

Для режима наблюдения:

```bash
npx sass --watch scss/styles.scss css/styles.css
```

## Структура SCSS

Файл `scss/styles.scss` собирает модули:

- `scss/_variables.scss` — цвета, интервалы и размеры.
- `scss/_mixins.scss` — повторяемые стили (`container`, `button`).
- `scss/_base.scss` — базовая типографика и сбросы.
- `scss/_layout.scss` — сетка страницы, шапка, hero, каталог и адаптивность.
- `scss/components/_card.scss` — карточки товара.
- `scss/components/_filters.scss` — фильтры.
- `scss/components/_badge.scss` — бейджи.

## Важные особенности

- Используются SCSS-переменные для цветов, радиусов и отступов.
- Для повторяемых блоков применён mixin.
- В проекте добавлены два breakpoint: для перестройки layout и для мобильной навигации.
- Карточки перечислены в HTML по строкам исходного CSV.
- Фильтр категорий работает без скриптов на radio-кнопках и CSS-селекторе `:has()`.
- Цвета, радиус и интервал из `dataset/theme.json` отражены в SCSS-переменных.

## Проверка

Для проверки достаточно открыть страницу на ширинах 375, 768 и 1440 пикселей и убедиться, что отсутствует горизонтальная прокрутка.
